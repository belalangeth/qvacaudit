QvacAudit
A Solana smart contract auditor that runs the AI locally. Your code never leaves your machine.
qvacaudit.xyz
01
The problem
Every AI tool that audits smart contracts sends your code to a remote server.

That's fine for public repos. But pre-launch programs have real value — leaked logic means someone can front-run your deploy or find exploits before you do.

Existing options: pay an audit firm, use a cloud AI and hope they don't log it, or ship and pray.
// solution
Local AI audit.
Zero data leaves the machine.
01
Paste your Rust program
Any Anchor or native Solana program. The editor takes raw .rs source code.
02
QVAC runs the model locally
LLM loads into server memory via @qvac/sdk. Inference happens on-device, CPU only, no GPU required.
03
Findings stream back in real time
Results arrive token-by-token over SSE. Severity levels, locations, and concrete fixes.
